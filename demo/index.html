The Mechanism

Score → Verify → Learn → Compound

Every decision teaches. Every verification strengthens. The system earns its autonomy — it doesn't assume it.

Score

Domain-specific factors (4–7 per domain). ProfileScorer computes action probabilities via L2 distance to learned centroids. No black box — every factor's contribution visible.

Verify

Human confirms or overrides the recommendation. Confirms update centroids gently (η=0.05). Overrides update more cautiously (η=0.01) with asymmetric penalty. The system learns from both.

Learn

Centroids drift toward verified outcomes: μ_c ← μ_c + η·y·(v − μ_c). Every category builds its own judgment geometry. Decisions that don't pass the conservation gate don't compound.

Compound

Accuracy rises. The system earns autonomy — categories that prove reliable get auto-routing. Cross-domain patterns transfer. The gap widens with every cycle.

For Architects

Under the hood

Graph Attention Engine

Open source: pip install graph-attention-engine

~844 parameters. Apache 2.0. 1,280 tests. ProfileScorer computes L2 distance to learned centroids — softmax over category prototypes. No neural network. No GPU. Runs on a laptop.

Conservation Law

θ_min = 23.53 / (α × V). The system cannot grant autonomy until it has enough verified decisions to bound error at the 95th percentile. Domain-specific penalty ratios (20:1 for SOC, 5:1 for S2P) make the threshold contextual. Not a hyperparameter — a mathematical gate.

Centroid Update Rule

μ_c ← μ_c + η · y · (v − μ_c)

Same equation in every copilot. Different centroids, different geometries. Confirms: η = 0.05. Overrides: η = 0.01. The asymmetry is the safety mechanism.
