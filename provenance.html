How to Reproduce

  • Clone the cross-graph-experiments repo (mirrored in Drive)
  • Install: pip install numpy matplotlib scipy pandas pyyaml
  • Each experiment script is standalone — runs from its directory, writes JSON + PNG/PDF to results/
  • Chart scripts read JSON results → produce publication-quality figures
  • Runner scripts batch multiple experiments
# Single experiment
python experiments/e_jm_1_personnel_change.py
# → results/e_jm_1/ (JSON summary + PNG + PDF)

# Batch (E-JM-1 through E-JM-4)
python run_all_experiments.py

# All harnesses
python run_all_harnesses.py

# EXP-C1 charts from existing results
python experiments/expC1_centroid_oracle/expC1_charts.py
# → paper_figures/expC1_*.{png,pdf}
